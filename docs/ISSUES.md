# Dogfood issue list

One list for everything found while using the app for real. Newest at the top.

**Priorities**
- **P0**: wrong money (a balance, an amount, a due date is wrong), data loss, cannot sign in, a due date notification missed or sent twice. Stop and fix today.
- **P1**: a feature you need does not work, or something is confusing enough that you made a mistake. Fix before the two-week clock counts.
- **P2**: annoying or cosmetic. Collect; fix only if cheap.

**Entry format**

```
### YYYY-MM-DD  P1  Short title
What I did:
What I expected:
What happened (screenshot, amount, entry name):
Health report / Recent errors at the time:
Status: open | fixed in <commit> | wont-fix (why)
```
